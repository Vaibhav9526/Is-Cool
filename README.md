# IsCool

A school of AI tutors on your own machine: Teacher, Topper, Smart Guy and Librarian,
plus the Vice Principal who runs the floor. Ported from Jargon with only the School part.

- Chat with any character; paste or attach an image or PDF and they answer from it.
- `@teach-me` opens the hosted interactive classroom, `@quiz` builds MCQs from your doubt.
- `@handwritten` makes a hand-written style PDF answer with diagrams.
- The Librarian keeps your notes and runs `@convert` / `@compress` locally.

## Run

`npm run dev` (see AGENTS.md for the Windows install workaround).
